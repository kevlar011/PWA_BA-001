# KEVLAR — project memory

A personal finance terminal for one person: an offline-first PWA, kept by BRIC.
Built with Claude. (It used to be a "mainframe" hosting a Docket subsystem and an empty
slot; both were removed 2026-10-25 at the user's request — KEVLAR is the ledger.)
Everything lives on the device; sync is optional and end-to-end encrypted.

Live: GitHub Pages at `/PWA_BA-001` (see `app.json` → `experiments.baseUrl`).
This repo is **public** — never commit keys, tokens, passphrases or `.env` files.

## Stack & build

- Expo SDK 57, expo-router (typed routes), React Native 0.86 → web, React 19.2
- zustand + `persist` → AsyncStorage (localStorage key `kevlar-v2`)
- reanimated 4 for motion, no UI kit, no bundled fonts
- `web.output: "single"` — pure SPA. The store touches storage at import time, so
  static prerendering would crash. `+html.tsx` therefore does nothing; the PWA head
  is injected after export by `scripts/finalize-web.js`.
- Deploy: push to `main` → `.github/workflows/deploy.yml`
  (`make-icons.js` → `expo export --platform web` → `finalize-web.js` → Pages)
- Icons are generated by `scripts/make-icons.js` (hand-rolled PNG encoder, no deps)
- Service worker `public/sw.js`: cache name `kevlar-v7-ledger`. **Bump the name** to
  force every installed copy to drop its old build.
- Dev server: `.claude/launch.json` → `npx expo start --web --port 8081`
- Path alias `@/*` → `src/*`

## Data rules (do not break these)

- One document, `KevlarData`: categories, transactions, budgets, goals, recurring,
  tasks, settings. Shared owner, key and merge pass.
- `tasks` is the **retired docket**. No UI reads it, but it is still persisted, merged,
  synced and backed up so old notes are never silently lost. Don't remove the plumbing
  without asking the user.
- **Debts are goals** with a `debt: { aprBps, minPayment }` block: `target` = owed when
  entered, `saved` = paid off. Savings screens filter them out with `isDebt`. Paying a
  debt also logs an expense (note `Debt payment · name`). `settings.debtExtra` = extra
  per month for the planner.
- **Money is integer minor units (cents).** Never floats.
- Every syncable record is `Tracked` (`updatedAt`, optional `deletedAt`). **Deletes are
  tombstones** — set `deletedAt`, never splice. To undo a delete, clear `deletedAt` and
  bump `updatedAt` (`undeleteTransaction`). Never re-insert a copy:
  duplicate ids let the tombstone win on the next merge.
- Screens use `useData()`, which filters tombstones out.
- Settings merge **field by field** via `settings.fieldTimes`; `updateSettings` stamps
  each patched key. Only stamp fields the user actually set (see onboarding).
- Device-only settings never travel: `syncUrl, syncKey, passphrase, passphraseCheck,
  syncedAt, aiKey` (stripped in `sync.ts forUpload`, preserved in `merge.ts DEVICE_ONLY`).
  Any new secret stored in settings must be added to **both** lists. `aiKey` is also
  stripped from backup exports (settings.tsx) and preserved across restore/adopt.
- Categories are archived, not deleted.
- Adding a list to `KevlarData`? Update `partialize`, persist `merge`, `restore`,
  `autosync.snapshot/signature`, `mergeData`, `pruneTombstones`, settings export.

## Sync

Supabase REST table `kevlar_sync(id text pk, blob jsonb, updated_at)`, deliberately open
RLS. Passphrase → PBKDF2 (310k, fixed domain salts) → AES-GCM key, and separately →
row id. Device pulls, decrypts, merges, prunes tombstones > 1 yr, seals, pushes.
Triggers: app open, foreground, 6 s after edits settle, 45 s poll while visible
(`MIN_GAP_MS` 20 s). `pullOnly` = adopt a new device without merging.

## BRIC's neural link (DeepSeek)

BRIC is a live LLM. No static lines remain in `lib/bric.ts`.

- **Key safety:** the site is static on public Pages, so a key built into the bundle
  would be public. The user pastes a DeepSeek key in Settings → stored in
  `settings.aiKey` on that device only (see data rules). The browser calls
  `https://api.deepseek.com/chat/completions` directly (CORS is allowed).
  **Never** put a key in code, `.env`, CI secrets that reach the bundle, or commits.
- Model `deepseek-flash` (default) or `deepseek-v4-pro`; thinking disabled for speed;
  JSON mode (`response_format: json_object`) for briefing/advisory.
- **Grounding:** `ledgerSummary()` sends pre-formatted figures, debts, leaks and
  `buildFindings()` readouts; the model judges and speaks, the device does the arithmetic.
  Task data is never sent.
- **Surfaces:** briefing (bank home, cached by data fingerprint +
  day-part), advisory (cached per fingerprint + day), statement verdict (`useRemark`),
  reactions after log/edit/delete/undo/restore/bills/zakat/tracked-leak/debt-added/debt-paid (`bricSay`: an uppercase system
  receipt shows instantly, BRIC's line types over it), and the `/bric` streaming chat.
- **Offline / no key / fault:** screens fall back to raw telemetry readouts and a
  `LinkStatus` fault line — nothing pretends to be BRIC.
- BRIC's memory (`kevlar-bric` storage) is device-only, never synced or backed up.
- Scripted copy that remains static by design: onboarding (before any key exists) and
  the 7-step tour.
- Ideas not built yet: tool calls so BRIC can log entries from chat; spoken replies via
  `speechSynthesis`.

## The look — amber phosphor CRT

One idea: a 1987 monochrome terminal someone wired to their bank.

- **Palette** (`theme/tokens.ts`): bg `#0B0A07` (warm, never pure black), surfaces
  `#141109 / #1E1910`, borders `#3A2F18`. Text is amber phosphor at three burn levels:
  `#FFC145` / dim `#B8863A` / faint `#6E5326`. Accent `#FFB000`.
- **Colour is rationed** — it appears only where money has a direction: income green
  `#4AE87A`, expense red `#FF5C4D`, info/transfer cyan `#5AD2FF`, warn `#FFD166`.
- Chrome, FAB, F-key strip and active states all take the accent amber.
- **Agency layer** (retrofuturist bureaucracy) for "official" surfaces: rust `#C2410C`
  form codes, mustard, bone, stamp red/green. `FileHeader` ("FORM K-04 / ANALYSIS" +
  double rule), `LeaderRow` (dotted leaders like a printed ledger), `Stamp` (rotated
  outlined rubber stamp), `FieldLabel`.
- **Type**: monospace everywhere (`ui-monospace`/SF Mono/Menlo stack), sizes bumped
  ~15%. Labels UPPERCASE with `spaced` letter-spacing. Buttons render as `[ SAVE ]`.
- **Shape**: radius 0–3. No circles except status LEDs. Frames with the label notched
  into the top border (`Card label="..."`).
- **ASCII furniture**: `▸` arrows/section markers, `▓░` segmented bars (`Bar`),
  `█` blinking cursor, `─ ═` rules, `✓ ✕`.
- **Motion**: `Rise` staggered entrances (40–60 ms steps), typewriter text for unit
  speech, rolling numbers, springy `Tap` with haptics, scanline overlay on web,
  boot sequences. Charming, short, never blocking.
- **Navigation**: `SystemBar` masthead `KEVLAR`, tab bar is an F1–F5 function-key strip.

## The unit

BRIC, an original construct (`components/ui/agency.tsx`). Moods: `idle | happy | warn | alarm | think`.

**BRIC — Banking.** An Iron-Man-style HUD reactor (`bric-core.tsx`): tick bezel, racing
scanner arcs, inner dashed ring and a pulsing core, all SVG + reanimated rotation — the
one sanctioned exception to "no circles". States: idle (drift), thinking (rings spin up),
speaking (core pulses fast), offline (grey, still). Every `<Bric>` follows the global
link state from `bric-store`, so all cores spin together while he thinks. Mood colours:
idle amber, happy green, warn yellow, alarm red, think cyan. Voice (now in the persona
prompt in `lib/bric.ts`): an impeccably polite, unflappable, quietly amused butler who has read every
line of your ledger and formed private opinions. Calls the user "sir", uses the name
when he wants attention. Courteous first, honest always, never fawning. Dry British
understatement ("Nothing has exploded financially. A low bar, admittedly."). Never
congratulates while you're overdrawn. Hard rule: explains principles and does
arithmetic, **never names investments** (not licensed); religious rulings → "ask your
scholar". Islamic mode (default on): riba warnings, zakat with hawl tracking.

## Leak scan & debts

- `scanLeaks()`: expense groups (normalised note, or category+exact amount when there is
  no note) with ≥3 charges, median gap at a weekly/monthly/yearly rhythm, amounts within
  15%, seen within two cycles, and not on the recurring list → "untracked repeat". Plus
  categories whose last closed month is ≥25% and ≥20.00 above the 3 before (needs 4
  months of history) → "creep". Top 3 become findings; the Advisor shows them all with
  yearly cost and `TRACK AS BILL` (adds a recurring).
- `comparePlans()`: month-by-month sim in cents, constant budget (minimums + extra, so a
  cleared debt's minimum rolls over), avalanche vs snowball, best = sooner then cheaper,
  "never" past 600 months. Islamic mode adds a `riba-debt` finding for any debt with a
  rate.

## Conventions

- Comments explain *why*, in full sentences, in the same dry voice. Match it.
- Screens compose `Screen` → `Rise` → `Card`/`SectionTitle`/`LeaderRow`; style via
  `StyleSheet.create` at the bottom named `s`.
- Transient UI state lives in `lib/session.ts` (not persisted): toasts with undo,
  syncing flag, lock state, boot-played flag.
- Every destructive or logging action speaks through `say(text, { mood, undo })`.
- Haptics only through `haptic()` / `notify()` (they throw on web).
